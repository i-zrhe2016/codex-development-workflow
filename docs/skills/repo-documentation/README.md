# Repo Documentation

`repo-documentation` contains repository-specific documentation contracts only. Codex performs normal documentation writing, editing, summarization, and reasoning natively.

Runtime contract: [`skills/repo-documentation/SKILL.md`](../../../skills/repo-documentation/SKILL.md).

Repository-specific rules cover:

- one canonical owner per fact;
- one reachable documentation router;
- file/type/lifecycle standards under the Skill's `references/`;
- mandatory Documentation Impact records;
- repository diagram source/render synchronization.

The Skill should not grow into a generic writing guide or documentation workflow.
