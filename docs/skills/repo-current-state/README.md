# Repo Current State

`repo-current-state` maintains `docs/Repo_Current_State.md` as a concise, verified snapshot of repository facts. The source skill is [`skills/repo-current-state/`](../../../skills/repo-current-state/).

The state note is an orientation aid. It is not a changelog, decision log, backlog, test archive, or permissions record. Verify task-relevant claims against repository evidence and refresh the note when represented facts materially change.
