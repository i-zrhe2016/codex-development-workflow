# Plan to Ticket

`plan-to-ticket` defines one requirement-level Plan and complete behavioral
Ticket execution/acceptance contracts. It persists new work in versioned Plan
Markdown and continues existing Issue requirements on their original authority.
It does not implement product changes or authorize publication.
