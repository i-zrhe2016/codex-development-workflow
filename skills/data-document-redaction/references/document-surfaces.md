# 文档表面与验证清单

视觉上看不见的内容常常比正文更容易漏掉。根据实际格式选择检查项；无法读取的部分必须标记 `needs_review`。

| 格式 | 必查表面 |
|---|---|
| PDF | 正文文字、扫描图像、OCR 文本层、标注/批注、书签/大纲、表单默认值、元数据/XMP、图层、附件/嵌入文件、JavaScript/动作、链接目标、页面缩略图、增量保存历史、文件名 |
| DOCX | 正文、页眉页脚、脚注尾注、批注、修订/删除文本、隐藏文字、文档/自定义属性、超链接、嵌入 OLE/图片、文本框、内容控件、custom XML、文件名 |
| XLSX | 隐藏/非常隐藏工作表、隐藏行列、批注/线程、公式与缓存值、命名区域、外部链接、数据验证、筛选条件、图表/透视缓存、宏、工作簿属性、文件名 |
| PPTX | 幻灯片、备注页、评论、隐藏幻灯片、母版/版式、替代文字、演讲者信息、嵌入媒体、超链接、文档属性、文件名 |
| 图片/扫描件 | EXIF/XMP/IPTC、GPS、缩略图、alpha 通道、隐藏像素、版本历史、OCR 结果、二维码/条形码、文件名 |
| 文本/日志/JSON/SQL | 注释、调试输出、请求头、URL 查询参数、Cookie、环境变量、堆栈、转义/编码后的值、base64/hex、压缩包内文件、备份和临时文件 |

## 一次流程最低证据

一次处理流程至少要组合一条结构/文本证据和一条视觉或独立读取证据；报告中写明工具、版本、覆盖范围和未检查面。

| 类型 | 结构/文本证据 | 视觉或独立读取证据 |
|---|---|---|
| PDF | 用合适的解析器全文搜索、选择/复制、抽取文本；检查元数据、书签、批注、表单、附件、链接和原始对象标记 | 重新打开并渲染页面；高敏感或扫描件逐页确认遮盖、图像、重复页眉和 OCR 结果 |
| DOCX/XLSX/PPTX | 应用级重开 + ZIP/XML/关系文件扫描；检查修订、批注、隐藏区域、备注、属性、外链和嵌入对象 | 重新渲染或用不同办公套件打开，确认版式、分页、隐藏面和图像中的文字 |
| 图片/扫描件 | 清理后重新 OCR/条码识别；检查 EXIF/XMP/IPTC、缩略图、alpha 和文件名 | 像素级查看每个脱敏区域；确认遮盖不是半透明、可逆模糊或仍可辨识的图层 |
| 数据/日志/文本 | 规则集扫描精确值、昵称/缩写/编码变体、秘密模式及压缩副本；比较 schema/计数/关系 | 抽样查看自由文本、导出预览和实际消费路径；记录未覆盖字段与抽样范围 |

自动检测结果只证明检测器看到了什么，不证明图像、logo、手写内容、重复页眉或 OCR 误读已经安全处理。任一必要证据路径缺失，都不要把结果写成 `pass`。

## PDF 安全发布流程

1. 复制到新路径，保留原件权限和校验值。
2. 使用真正的 redaction 工具标记并 **apply**；绘制矩形、荧光笔或普通 annotation 只是在上面盖层，不能作为删除。
3. 运行 sanitize/移除隐藏信息，至少处理元数据、注释、书签、表单、附件、脚本和图层。
4. 高敏感文件可在确认版式允许后栅格化/扁平化；这不能替代前两步。
5. 改用中性的文件名，清理导出目录中的临时副本。
6. 用不同的阅读器或解析器打开：全文搜索禁止词，尝试选择/复制遮盖区域，抽取文本，检查属性、书签、注释、表单、附件、链接和 OCR 层，并渲染每页确认覆盖没有漏字。
7. 任何一项失败都把输出标为 `needs_review`，不要交付。

## Office 文件安全发布流程

1. 接受或拒绝修订，删除批注和隐藏工作表/行列，清空不需要的公式、外部链接、命名区域和嵌入对象。
2. 检查页眉页脚、备注、文本框、替代文字、文档属性和文件名；必要时从 ZIP/XML 层面搜索敏感词。
3. 用应用级解析器重新打开，再用独立的 XML/文本扫描器复核；不要只依赖“检查文档”按钮。
4. 转成 PDF 只在接收者确实需要固定版式时进行，转后仍按 PDF 流程复核。

## OCR、图片和签名

- 先 OCR/提取再脱敏，确保图片中的文字、二维码和印章与可见文本一致；脱敏后再次 OCR/抽取验证。
- EXIF/GPS/作者/设备序列号和缩略图应按发布目的清理；不要用模糊处理代替像素级删除。
- 数字签名、证书、时间戳和法律效力文档在编辑或栅格化后可能失效；先暂停并让责任人确认是否需要保留签名证明。
